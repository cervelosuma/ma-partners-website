# M.A Partners 公式サイト

静的HTMLで作成した1ページの企業サイトです。GitHub Pagesへそのまま公開できます。スクロール連動背景、セクション表示アニメーション、スマートフォンメニューを含みます。

## 確認方法

`index.html` をブラウザで開いてください。

## GitHub Pagesへの公開

1. このフォルダ内のファイルをGitHubリポジトリへアップロード
2. リポジトリの `Settings` → `Pages`
3. `Deploy from a branch`、`main`、`/(root)` を選択して保存
4. 仮URLで表示を確認後、Custom domainに取得済みドメインを設定
